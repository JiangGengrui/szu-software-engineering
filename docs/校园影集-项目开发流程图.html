文档使用总则

四条规则贯穿六个阶段，适用于所有文档的引用、变更与验收。

01单一基线

PRD V1.1 定义需求、字段、错误码与验收口径；代码与下游文档不得偏离。出现冲突时，以 PRD 与冻结的接口字段为准。

02单向传导

需求变更沿「PRD → 用户故事 → 功能设计 / 架构设计 → 测试文档」同步；每次变更须评审、升版并在文档中留痕。

03ID 全链路

FR → US → P → TC 双向可追溯；代码提交、缺陷记录与测试结果必须引用对应 ID，避免口头约定。

04门禁与回归

每周五集成演示 + 阶段末文档核对；未通过则修复或按 PRD 2.3 降级并留痕。缺陷关闭须回归本用例、同路径用例与端到端主线。
